# VS Code Copilot Chat Onboarding

Welcome to the AdGenX AI team workspace! This onboarding guide will help you get set up with VS Code, Copilot Chat, and our team guardrails for secure, productive development.

## 1. Install Required Extensions

- [GitHub Copilot](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot)
- [GitHub Copilot Chat](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot-chat)
- [ESLint](https://marketplace.visualstudio.com/items?itemName=dbaeumer.vscode-eslint)
- [Prettier](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode)
- [EditorConfig](https://marketplace.visualstudio.com/items?itemName=EditorConfig.EditorConfig)

## 2. Workspace Settings

- Commit signing is enforced.
- Format on save and linting are enabled.
- Copilot Chat is configured for code block output and privacy.

## 3. Security & Guardrails

- All code must pass security CI and lint checks before merging.
- Sensitive data must never be committed (see `GUARDRAILS.md`).

## 4. Getting Help

- Use Copilot Chat for code suggestions, explanations, and troubleshooting.
- For onboarding issues, contact the DevOps lead or open a GitHub issue.

Happy coding! 🚀
