## 🎯 Quick Start Commands

### 1. Interactive Menu Launcher
```bash
cd adgenxai-gemini-cookbook
python main.py
```

**Menu Options:**
- `1` 📝 Text Generation (Agent-First patterns)
- `2` 🎨 Multimodal Input (Vision + text)
- `3` 🔧 Function Calling (Agent swarm coordination)
- `4` 🎯 Batch Processing (High-volume workflows)
- `5` ⚡ Voice Interaction (Real-time audio)
- `6` 🌐 **Fusion Dashboard** (Complete experience)
- `7` ❌ Exit

### 2. Direct Dashboard Launch
```bash
python app.py
```
Opens full-featured dashboard at: [http://127.0.0.1:8000](http://127.0.0.1:8000)

### 3. Setup Verification
```bash
python test_setup.py
```
Verifies API keys and dependencies.
