# Ghost CMS Integration

## Overview

The Ghost CMS integration allows you to publish AI-generated content directly from AdGenXAI to your Ghost website. Ghost is a powerful, open-source content management system designed for professional publishing.

## Features

- **Seamless Publishing**: Publish AI-generated content directly to Ghost
- **Draft or Live**: Choose to publish as draft or immediately go live
- **Tag Management**: Automatically tag AI-generated content
- **Batch Publishing**: Publish multiple posts at once
- **Content Management**: Update existing posts with new AI content

## Prerequisites

Before you can integrate Ghost with AdGenXAI, you need:

1. A Ghost site (self-hosted or Ghost(Pro))
2. Access to your Ghost Admin panel
3. API keys from Ghost

## Getting Your Ghost API Keys

### Step 1: Access Ghost Admin

1. Log in to your Ghost Admin panel at `https://your-site.com/ghost`
2. Navigate to **Settings** → **Integrations**

### Step 2: Create a Custom Integration

1. Click **Add custom integration**
2. Give it a name (e.g., "AdGenXAI")
3. Click **Create**

### Step 3: Copy Your API Keys

You'll see two API keys:

- **Content API Key**: Used for reading content from your Ghost site
- **Admin API Key**: Used for creating, updating, and deleting content

Copy both keys - you'll need them for the integration.

## Setting Up Ghost Integration in AdGenXAI

### Via Dashboard

1. Navigate to **Dashboard** → **Integrations**
2. Find the **Ghost CMS** card
3. Click **Connect Ghost Site**
4. Fill in the form:
   - **Ghost Site URL**: Your full Ghost site URL (e.g., `https://your-site.com`)
   - **Content API Key**: The Content API key from Ghost
   - **Admin API Key**: The Admin API key from Ghost
5. Click **Connect**

AdGenXAI will test the connection and confirm if successful.

### Via Environment Variables

You can also configure Ghost integration via environment variables:

```bash
GHOST_URL=https://your-ghost-site.com
GHOST_CONTENT_API_KEY=your_content_api_key_here
GHOST_ADMIN_API_KEY=your_admin_api_key_here
```

## Using the Integration

### Publishing AI-Generated Content

Once connected, you can publish AI-generated content to Ghost:

1. Generate content using AdGenXAI's AI tools
2. Navigate to the **Publish** section
3. Select **Ghost** as the publishing platform
4. Configure publishing options:
   - **Status**: Draft or Published
   - **Featured**: Mark as featured post
   - **Tags**: Add relevant tags
   - **Publish Date**: Schedule for future publication
5. Click **Publish to Ghost**

### Programmatic Usage

You can also use the Ghost integration programmatically:

```typescript
import { createGhostPublisher } from '@/lib/integrations/ghost';

const publisher = createGhostPublisher({
  url: 'https://your-ghost-site.com',
  contentApiKey: 'your-content-key',
  adminApiKey: 'your-admin-key'
});

// Publish AI content
const result = await publisher.publishAIContent({
  title: 'My AI-Generated Article',
  content: '<h1>Amazing Content</h1><p>Generated by AI...</p>',
  format: 'html',
  metadata: {
    provider: 'openai',
    generatedAt: new Date()
  }
}, {
  status: 'published',
  tags: ['ai-generated', 'advertising'],
  featured: true
});

if (result.success) {
  console.log('Published to:', result.postUrl);
}
```

## API Endpoints

### Test Connection

**POST** `/api/ghost/test-connection`

Tests connectivity to a Ghost site.

**Request Body:**
```json
{
  "url": "https://your-ghost-site.com",
  "contentApiKey": "your-content-key",
  "adminApiKey": "your-admin-key"
}
```

**Response:**
```json
{
  "success": true,
  "message": "Connected to Your Site Name",
  "siteName": "Your Site Name",
  "version": "5.0"
}
```

### Publish Content

**POST** `/api/ghost/publish`

Publishes content to Ghost.

**Request Body:**
```json
{
  "config": {
    "url": "https://your-ghost-site.com",
    "contentApiKey": "your-content-key",
    "adminApiKey": "your-admin-key"
  },
  "content": {
    "title": "Article Title",
    "content": "<h1>Content</h1>",
    "format": "html",
    "metadata": {
      "provider": "openai",
      "generatedAt": "2025-11-10T00:00:00Z"
    }
  },
  "options": {
    "status": "published",
    "tags": ["ai-generated"],
    "featured": false
  }
}
```

**Response:**
```json
{
  "success": true,
  "postUrl": "https://your-ghost-site.com/my-article",
  "postId": "507f1f77bcf86cd799439011",
  "message": "Content published successfully"
}
```

## Best Practices

### Content Quality

- **Review Before Publishing**: Always review AI-generated content before publishing
- **Add Human Touch**: Edit and personalize AI content for your audience
- **Use Drafts**: Publish as draft first to review on Ghost's preview

### SEO Optimization

- **Meta Descriptions**: Add custom meta descriptions
- **Featured Images**: Include relevant featured images
- **Tags**: Use consistent, relevant tags
- **Internal Links**: Add links to related content

### Performance

- **Batch Publishing**: Use batch publishing for multiple posts
- **Schedule Posts**: Schedule posts instead of publishing all at once
- **Monitor API Limits**: Be aware of Ghost API rate limits

## Troubleshooting

### Connection Failed

**Problem**: Cannot connect to Ghost site

**Solutions**:
- Verify your Ghost URL is correct (include https://)
- Check that API keys are copied correctly
- Ensure your Ghost site is accessible (not localhost)
- Verify Ghost version is 5.0 or higher

### Publishing Failed

**Problem**: Content fails to publish

**Solutions**:
- Verify Admin API key is provided (not just Content API)
- Check that the API key has write permissions
- Ensure content meets Ghost requirements (title, content not empty)
- Check Ghost logs for detailed error messages

### Missing Features

**Problem**: Some features don't work

**Solutions**:
- Update to latest version of Ghost (5.0+)
- Check that your Ghost plan supports the feature
- Verify integration permissions in Ghost Admin

## Security Notes

- **Never Commit API Keys**: Keep API keys out of version control
- **Use Environment Variables**: Store keys in environment variables
- **Rotate Keys Regularly**: Change API keys periodically
- **Monitor Usage**: Check Ghost Admin for unusual API activity
