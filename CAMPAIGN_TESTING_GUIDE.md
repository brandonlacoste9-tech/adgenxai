## Overview

The Campaign Orchestration API (`/api/campaign/orchestrate`) is the core feature of AdGenXAI. It orchestrates **5 specialized AI providers** in parallel to generate complete marketing campaigns from a single brief.

### What It Does

**Input**: A campaign brief (e.g., "Launch a new AI productivity tool for developers")

**Output**: Complete campaign assets including:
- 📝 Strategic plan (Kimi-Linear)
- 🖼️ Marketing images (EMU 3.5)
- 🎬 Video content (LongCat)
- 🎙️ Audio/voiceover (Ditto)
- 🖼️ Thumbnail previews (Nitro-E)

### Key Features

- ⚡ **Parallel execution** - All providers run simultaneously
- 💰 **Budget-aware** - Distributes budget across providers
- 🎯 **Mode selection** - Preview (fast) vs Production (quality)
- 🔄 **Smart caching** - Reuses similar requests to save cost
- 📊 **Provider health** - Circuit breaker pattern for resilience

## API Endpoint Reference

### POST /api/campaign/orchestrate

Generate a complete marketing campaign from a brief description.

#### Request Body

```typescript
interface CampaignRequest {
  // Required: Campaign description
  brief: string;

  // Optional: Generation mode
  // - 'preview': Fast, lower quality (default for free tier)
  // - 'production': High quality, slower, more expensive
  mode?: 'preview' | 'production';

  // Optional: Maximum budget in USD
  budget?: number;

  // Optional: User subscription tier
  userTier?: 'free' | 'pro' | 'enterprise';
}
```

#### Response

```typescript
interface CampaignResponse {
  // Generated campaign assets
  strategy: string;
  image: string;
  video: string;
  audio: string;
  thumbnail: string;

  // Provider execution details
  providers: {
    kimi: ProviderResult;
    emu: ProviderResult;
    longcat: ProviderResult;
    ditto: ProviderResult;
    nitro: ProviderResult;
  };

  // Metadata about the generation
  metadata: {
    totalCost: number;      // Total cost in USD
    totalDuration: number;  // Execution time in ms
    brief: string;          // Original brief
    generatedAt: string;    // ISO timestamp
  };
}
```

#### Error Responses

```typescript
// 400 Bad Request
{
  "error": "Brief is required and must be a string"
}

// 500 Internal Server Error
{
  "error": "Failed to orchestrate campaign",
  "details": "Provider timeout"
}
```

## Integration Examples

### JavaScript/TypeScript (Frontend)

```typescript
async function generateCampaign(brief: string) {
  try {
    const response = await fetch('/api/campaign/orchestrate', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        brief,
        mode: 'production',
        userTier: 'pro'
      })
    });

    if (!response.ok) {
      const error = await response.json();
      throw new Error(error.error);
    }

    const campaign = await response.json();

    console.log('Campaign generated!');
    console.log('Total cost:', campaign.metadata.totalCost);
    console.log('Duration:', campaign.metadata.totalDuration, 'ms');

    return campaign;

  } catch (error) {
    console.error('Campaign generation failed:', error);
    throw error;
  }
}

// Usage
const campaign = await generateCampaign(
  'Launch a subscription box service for pet owners'
);
```

### React Component

```tsx
import { useState } from 'react';

export function CampaignGenerator() {
  const [brief, setBrief] = useState('');
  const [campaign, setCampaign] = useState(null);
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState(null);

  const handleGenerate = async () => {
    setLoading(true);
    setError(null);

    try {
      const response = await fetch('/api/campaign/orchestrate', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ brief, mode: 'preview' })
      });

      if (!response.ok) {
        throw new Error('Failed to generate campaign');
      }

      const data = await response.json();
      setCampaign(data);

    } catch (err) {
      setError(err.message);
    } finally {
      setLoading(false);
    }
  };

  return (
    <div className="campaign-generator">
      <textarea
        value={brief}
        onChange={(e) => setBrief(e.target.value)}
        placeholder="Describe your marketing campaign..."
        rows={4}
      />

      <button
        onClick={handleGenerate}
        disabled={!brief || loading}
      >
        {loading ? 'Generating...' : 'Generate Campaign'}
      </button>

      {error && <div className="error">{error}</div>}

      {campaign && (
        <div className="campaign-results">
          <h3>Campaign Generated!</h3>
          <p><strong>Cost:</strong> ${campaign.metadata.totalCost.toFixed(2)}</p>
          <p><strong>Strategy:</strong> {campaign.strategy}</p>
          <p><strong>Image:</strong> {campaign.image}</p>
          <p><strong>Video:</strong> {campaign.video}</p>
        </div>
      )}
    </div>
  );
}
```

### Python Script

```python
import requests
import json

def generate_campaign(brief, mode='production'):
    """Generate a marketing campaign using the orchestration API"""

    url = 'http://localhost:3000/api/campaign/orchestrate'

    payload = {
        'brief': brief,
        'mode': mode
    }

    response = requests.post(url, json=payload)

    if response.status_code == 200:
        campaign = response.json()

        print(f"✓ Campaign generated!")
        print(f"✓ Total cost: ${campaign['metadata']['totalCost']:.2f}")
        print(f"✓ Duration: {campaign['metadata']['totalDuration']}ms")
        print(f"\nStrategy:\n{campaign['strategy']}")

        return campaign
    else:
        error = response.json()
        print(f"✗ Error: {error.get('error', 'Unknown error')}")
        return None

# Usage
campaign = generate_campaign(
    brief="Launch a fitness app targeting busy professionals",
    mode="preview"
)
```

## Performance & Cost Optimization

### Caching Strategy

The API automatically caches similar requests to reduce costs:

```typescript
// First request - generates new campaign
const campaign1 = await fetch('/api/campaign/orchestrate', {
  method: 'POST',
  body: JSON.stringify({
    brief: 'Launch a new coffee subscription service'
  })
});
// Cost: $0.47, Duration: 2500ms

// Second request (same brief) - uses cache
const campaign2 = await fetch('/api/campaign/orchestrate', {
  method: 'POST',
  body: JSON.stringify({
    brief: 'Launch a new coffee subscription service'
  })
});
// Cost: $0.00, Duration: 500ms (cache hit!)
```

**Cache behavior**:
- Preview mode: 5 minute TTL
- Production mode: 1 hour TTL
- Pro/Enterprise users: Longer TTL (cost savings)

### Budget Allocation

The API intelligently distributes budget across providers:

| Provider | Budget % | Reasoning |
|----------|----------|-----------|
| Video (LongCat) | 40% | Most expensive asset |
| Image (EMU) | 30% | Second most expensive |
| Strategy (Kimi) | 15% | Text generation is cheap |
| Audio (Ditto) | 10% | Standard voiceover |
| Thumbnail (Nitro) | 5% | Fast preview generation |

**Example with $1.00 budget**:
```json
{
  "brief": "Product launch campaign",
  "budget": 1.00,
  "mode": "production"
}
```

Results in:
- Video: $0.40 budget (30s @ premium quality)
- Image: $0.30 budget (high resolution)
- Strategy: $0.15 budget (comprehensive plan)
- Audio: $0.10 budget (professional voice)
- Thumbnail: $0.05 budget (quick preview)

### Mode Comparison

| Feature | Preview | Production |
|---------|---------|------------|
| **Speed** | ~2-3s | ~10-30s |
| **Cost** | ~$0.15-0.30 | ~$0.50-3.00 |
| **Video Length** | 5 seconds | 30 seconds |
| **Video Quality** | 720p, fast encode | 1080p, premium |
| **Provider** | Nitro-E (fast) | LongCat (quality) |
| **Use Case** | Testing, iterations | Final delivery |

## Troubleshooting

### Issue: High Latency (>10s response time)

**Symptoms**: Requests take longer than expected

**Possible Causes**:
1. Production mode with long video duration
2. Provider API slow/overloaded
3. Cold start (first request after idle)

**Solutions**:
```bash
# Check provider health
curl http://localhost:3000/api/providers/health

# Use preview mode for faster iterations
{
  "brief": "...",
  "mode": "preview"  // Much faster!
}

# Reduce video duration (if custom)
{
  "brief": "...",
  "duration": 10  // Shorter = faster
}
```

### Issue: Unexpected High Costs

**Symptoms**: `totalCost` exceeds budget or expectations

**Possible Causes**:
1. Using production mode instead of preview
2. No budget limit set
3. Cache disabled/not hitting

**Solutions**:
```bash
# Set explicit budget
{
  "brief": "...",
  "budget": 0.50  // Hard limit
}

# Use preview mode for testing
{
  "brief": "...",
  "mode": "preview"  // Lower cost
}

# Check cache status in response
{
  "providers": {
    "kimi": {
      "cacheStatus": "hit"  // ✅ Cost savings!
    }
  }
}
```

### Issue: 400 Bad Request - "Brief is required"

**Symptoms**: Request fails with validation error

**Cause**: Missing or invalid `brief` parameter

**Solution**:
```bash
# ✗ Wrong
{ }

# ✗ Wrong
{ "brief": null }

# ✗ Wrong
{ "brief": "" }

# ✓ Correct
{ "brief": "Launch a new product" }
```

### Issue: 500 Internal Server Error

**Symptoms**: Server error during campaign generation

**Possible Causes**:
1. Provider API failure
2. Network timeout
3. Invalid provider configuration

**Debug Steps**:
```bash
# 1. Check server logs
npm run dev
# Look for error stack traces

# 2. Verify environment variables
cat .env.local
# Ensure provider API keys are set

# 3. Test individual providers
curl http://localhost:3000/api/providers/validate

# 4. Check provider health
curl http://localhost:3000/api/providers/health
```

### Issue: Inconsistent Results

**Symptoms**: Same brief generates different outputs

**Explanation**: This is expected behavior!

AI generation is non-deterministic by design. Each request:
- Uses different random seeds
- May hit different cache states
- Can route to different provider instances

**To get consistent results**:
```typescript
// Rely on caching - same brief within TTL returns cached result
const result1 = await generate(brief); // Cost: $0.47
const result2 = await generate(brief); // Cost: $0.00 (cached, identical)
```
